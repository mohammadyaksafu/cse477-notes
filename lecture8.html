    Prime Number ও Factorization

    Prime p: একটা integer, p ≥ 2, যার একমাত্র ভাজক 1 ও p। (Integer = পূর্ণসংখ্যা, ঋণাত্মকও হতে পারে, ভগ্নাংশ নয়।)

    • 2, 7, 19 → prime ✅
    • −3, 0, 1, 6 → prime নয় ❌
    Prime decomposition: n = p1e1 × p2e2 × … × pkek উদাহরণ: 200 = 2³ × 5²
    🎯 Fundamental Theorem of Arithmetic

    একটা ধনাত্মক integer-এর prime decomposition অনন্য।

    🧪 Factorizer

    GCD ও Euclid-এর Algorithm

    gcd(a, b) = a ও b দুটোকেই ভাগ করে এমন বৃহত্তম ধনাত্মক integer।

    gcd(18, 30) = 6 gcd(0, 20) = 20 gcd(−21, 49) = 7

    gcd(a, b) = 1 হলে a ও b relatively prime (সহমৌলিক)। যেমন gcd(15, 28) = 1।

    Euclid-এর algorithm

    gcd(a, b) = gcd(b, a mod b) Algorithm EuclidGCD(a, b) if b = 0 return a else return EuclidGCD(b, a mod b)

    📖 গল্প

    412 × 260 সেমি একটা মেঝেতে সবচেয়ে বড় বর্গাকার টাইল বসাতে চাও যাতে কাটতে না হয়। প্রথমে 260×260 টাইল বসাও, বাকি থাকে 152×260; আবার 152×152 বসাও… শেষে 4 সেমির টাইল সব ঢেকে দেয়। gcd = 4!

    Modular Arithmetic

    r = a mod n ⇔ a = r + k·n (k = quotient q, r = remainder) 29 mod 13 = 3 (29 = 3 + 2×13) 13 mod 13 = 0 (13 = 0 + 1×13) −1 mod 13 = 12 (−1 = 12 + (−1)×13)
    📖 গল্প

    ঘড়ি হলো mod 12! এখন ১০টা, ৫ ঘণ্টা পর কয়টা? (10 + 5) mod 12 = 3টা। আর −1 mod 13 = 12 মানে ঘড়ির কাঁটা শূন্য থেকে এক ঘর পেছালে শেষ ঘরে যায়।

    Multiplicative inverse

    Zn = {0, 1, 2, …, n−1}। যদি x·y mod n = 1 হয়, তাহলে y = x−1 mod n।

    🎯 Theorem ও Corollary
    • Zn-এর x-এর inverse থাকবে যদি এবং কেবল যদি gcd(x, n) = 1।
    • n = p prime হলে Zp-এর প্রতিটা nonzero উপাদানের inverse আছে।
    🧪 Inverse ও Power টেবিল

    n = 10 দিয়ে দেখো: inverse আছে শুধু 1, 3, 7, 9-এর (যারা 10-এর সাথে সহমৌলিক)। n = 7 বা 13 (prime) দিলে সবার power কোনো এক সময় 1 হয়।

    Fermat-এর Little Theorem ও Euler-এর Theorem

    p prime, x ∈ Zp nonzero ⇒ xp−1 mod p = 1 p = 5: 1⁴ mod 5 = 1 2⁴ = 16 mod 5 = 1 3⁴ = 81 mod 5 = 1 4⁴ = 256 mod 5 = 1

    Corollary: x-এর inverse = xp−2 mod p, কারণ x · xp−2 = xp−1 ≡ 1।

    Zn* = Zn-এর যেসব উপাদান n-এর সাথে সহমৌলিক। Totient Φ(n) = |Zn*|।

    Z10* = {1, 3, 7, 9} Φ(10) = 4 p prime: Zp* = {1, 2, …, p−1} Φ(p) = p − 1 Theorem: x ∈ Zn* ⇒ xΦ(n) mod n = 1 3⁴ mod 10 = 81 mod 10 = 1 7⁴ = 2401 mod 10 = 1 9⁴ = 6561 mod 10 = 1

    Fermat হলো Euler-এর বিশেষ রূপ (n = p হলে Φ(p) = p−1)।

    RSA Cryptosystem

    উদ্ভাবক Ron Rivest, Adi Shamir, Leonard Adleman (1977)। ভিত্তি: দুটো বড় prime-এর গুণফলকে factorize করা বাস্তবে কঠিন। সবচেয়ে বহুল ব্যবহৃত cryptosystem; ২০০২ সালে তাঁরা Turing Award (CS-এর নোবেল) পান।

    সাধারণ রূপস্লাইডের উদাহরণ
    Setupn = p·q (p, q বড় prime)
    Φ(n) = (p−1)(q−1)
    e: gcd(e, Φ(n)) = 1
    d = e−1 mod Φ(n) (d·e mod Φ(n) = 1)    		p = 7, q = 17
    n = 119
    Φ(n) = 6 × 16 = 96
    e = 5, d = 77 (5×77 = 385 = 4×96 + 1)
    KeysPublic Ke = (n, e); Private Kd = dPublic (119, 5); Private 77
    EncryptC = Me mod nM = 19 → C = 19⁵ mod 119 = 66
    DecryptM = Cd mod n66⁷⁷ mod 119 = 19 ✅

    দুটো গোপন রঙ (p, q) মিশিয়ে একটা নতুন রঙ (n) বানানো সহজ। কিন্তু শুধু মিশ্র রঙ দেখে কোন দুটো রঙ মেশানো হয়েছে বের করা প্রায় অসম্ভব। Bob মিশ্র রঙটা সবাইকে দেয় (public), আর মূল রঙ দুটো (তাই Φ(n) ও d) গোপন রাখে।

    🧪 RSA Playground

    Correctness — কেন Cd = M?

    ধরি gcd(M, n) = 1 (p, q খুব বড়, তাই এরা M-এর গুণনীয়ক হওয়ার সম্ভাবনা খুব কম)।

    e·d mod Φ(n) = 1 → কোনো integer k-এর জন্য e·d = k·Φ(n) + 1

    Euler: MΦ(n) mod n = 1

    Cd mod n = Med mod n = MkΦ(n)+1 mod n = M · (MΦ(n))k mod n = M · 1k = M ✅

    RSA-র নিরাপত্তা ও Determinism

    • নিরাপত্তা নির্ভর করে e ও n থেকে d বের করার কঠিনতার উপর।
    • Φ(n) = (p−1)(q−1) জানলে extended Euclid দিয়ে d = e−1 mod Φ(n) সহজেই বের হয় → তাই p, q গোপন রাখো (বা মুছে ফেলো)।
    • অর্থাৎ RSA-র নিরাপত্তা = n factor করার কঠিনতা। যথেষ্ট বড় modulus হলে নিরাপদ।
    • 1999: 512-bit চ্যালেঞ্জ factor হয় ৪ মাসে, 35.7 CPU-year (শত শত SGI, Sun, Pentium II মেশিন)।
    • 2005: RSA-640 — 30টা 2.2GHz CPU-year।
    • 2004: RSA-2048 factor করার পুরস্কার ছিল $200,000।
    • বর্তমান practice: 2,048-bit key।

    Decryption-এর সময় বা CPU-র বিদ্যুৎ খরচ মেপে side-channel আক্রমণ। USENIX Security ’18 (Alam et al.): মোবাইল ডিভাইস থেকে, শারীরিক access ছাড়াই, কয়েক সেকেন্ডে key উদ্ধার — modular exponentiation-এর সময় প্রসেসর থেকে অনিচ্ছাকৃত analog signal থেকে exponent-এর bit পড়ে।

    RSA deterministic: একই public key-তে একই M → একই C। তাই C1 = C2 হলে M1 = M2 — cryptanalyst তথ্য অনুমান করতে পারে।

    🧪 Repeated squaring

    ab mod n করতে লাগে সর্বোচ্চ 2·log₂(b) টা গুণ, আর কখনো n²-এর চেয়ে বড় সংখ্যা নিয়ে কাজ করতে হয় না।

    ২. Extended Euclid — inverse বের করা

    যেকোনো a, b-এর জন্য এমন i, j আছে যে i·a + j·b = gcd(a, b) = d। যেমন a = 21, b = 15: 3 = 3×21 + (−4)×15।

    x-এর inverse Zn-এ: (x, n)-এ extended Euclid চালাও → (d, i, j)। d = 1 হলে i-ই inverse; d > 1 হলে inverse নেই।

    ৩. Primality testing — Fermat test

    n > 1, র‍্যান্ডম a, 1 < a < n−1: an−1 mod n ≠ 1 ⇒ n অবশ্যই composite an−1 mod n = 1 ⇒ n সম্ভবত prime

    এই test-গুলো n-কে factor করে না, শুধু বলে prime কি না। 1 থেকে n-এর মধ্যে prime অন্তত n / ln n টা (n ≥ 4), তাই র‍্যান্ডম সংখ্যা নিয়ে logarithmic সংখ্যকবার test করলেই একটা prime পাওয়া যায়।

    🧪 Fermat test

    561 = 3×11×17 একটা Carmichael সংখ্যা — gcd(a,561)=1 এমন সব a-কে বোকা বানায়! তাই বাস্তবে Miller–Rabin ব্যবহার হয়।

    ৪. সাধারণ ব্যবহার (Hybrid)

    র‍্যান্ডম AES key K→ RSA দিয়ে encrypt →RSA(K)+AESK(document)→ একসাথে পাঠাও

    RSA AES-এর চেয়ে কয়েক order of magnitude ধীর, তাই এভাবেই ব্যবহার হয়।
