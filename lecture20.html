    LECTURE 20

    Network Attacks I — Sniffing, Scanning, ARP ও IP Spoofing

    আক্রমণের দুই ধরন ও চার হুমকি, MITM, packet sniffing ও তা ধরা/ঠেকানো, footprinting ও scanning (ping sweep, port scan, nmap), তারপর active আক্রমণ: ARP spoofing ও IP spoofing (blind / non-blind) এবং তাদের প্রতিকার।

    Interception · Modification · Fabrication · InterruptionMITMARP watchnmapARP spoofingIP traceback

    আক্রমণ ও হুমকির ধরন

    🔨 Active attack

    Target-কে modify, misconfigure বা disrupt করে — প্রসেস/সিস্টেম/ডেটা বদলানো, communication channel বিঘ্নিত করা।

    👂 Passive attack

    Target-কে না বদলে শুধু পর্যবেক্ষণ।

    চার ধরনের হুমকি (Threat)

    Threatঅর্থকোন লক্ষ্য ভাঙেধরন

    📖 ডাকপিয়নের উপমা

    অসৎ ডাকপিয়ন চিঠি খুলে পড়ল (interception), লেখা বদলে দিল (modification), নিজেই একটা ভুয়া চিঠি লিখে দিল (fabrication), চিঠি ফেলেই দিল (interruption)।

    Passive আক্রমণ

    • Eavesdropping (Sniffing) — অন্যের packet শোনা।
    • Footprinting (Network mapping) — সিস্টেমে কী সফটওয়্যার আছে পরীক্ষা করা।

    মুছে ফেলা

    Charlie কে হতে পারে? — ISP, VPN provider, কফিশপের WiFi provider, অথবা তোমার connection re-route করা কোনো attacker।

    💡 MITM scenario

    তুমি ক্যাফের ফ্রি WiFi “Cafe_Free”-তে যুক্ত হলে — কিন্তু সেটা আসলে পাশের টেবিলের হ্যাকারের ল্যাপটপের hotspot। তোমার সব ট্রাফিক তার মাধ্যমে ইন্টারনেটে যাচ্ছে; HTTP হলে সে সব পড়তে ও বদলাতে পারে।

    Packet Sniffing

    নেটওয়ার্ক দিয়ে যাওয়া তথ্য “পড়া”। Sniffer packet আটকায়, প্রায়ই ARP cache poisoning দিয়ে। Sniffer software বা hardware হতে পারে, এবং নেটওয়ার্ক সেটআপের উপর নির্ভরশীল।

    • নেটওয়ার্ক ব্যবহার মনিটর
    • ট্রাফিক filter
    • নেটওয়ার্ক সমস্যা বিশ্লেষণ (যেমন Wireshark)
    • তথ্য চুরি — password, কথোপকথন
    • আক্রমণের প্রস্তুতির জন্য নেটওয়ার্ক তথ্য বিশ্লেষণ

    Sniffer ধরা (Detecting)

    • Sniffer প্রায় সবসময় passive — শুধু ডেটা জমায়, তাই ধরা খুব কঠিন।
    • Switched নেটওয়ার্কে সমাধান: ARP watch — ARP cache-এ একই মেশিনের duplicate entry দেখলে alarm।
    • সমস্যা: false alarm — বিশেষত DHCP নেটওয়ার্কে একই মেশিনের একাধিক এন্ট্রি স্বাভাবিক।

    Sniffer ঠেকানো (Stopping)

    • সেরা উপায়: packet নিরাপদে encrypt করা — sniffer ধরলেও সব garbage।
    • SSH — public/private key pair থাকায় sniffing প্রায় অকেজো।
    • Switched নেটওয়ার্কে প্রায় সব আক্রমণ ARP spoofing দিয়ে → মেশিনগুলো cache-এর permanent (static) store-এ রাখো; broadcast reply দিয়ে তা বদলানো যায় না।
    • সবচেয়ে ভালো: ঢুকতেই না দেওয়া — sniffer-কে তোমার subnet-এ থাকতে হয়, আর চালু হতে কোনো এক সময় root লাগে।

    Footprinting ও Scanning

    Footprinting প্রায়ই আক্রমণের প্রথম ধাপ — target সম্পর্কে তথ্য সংগ্রহ। Scanning দিয়ে জানা যায়: কোন OS, কোন সার্ভিস চলছে, কোনো configuration ভুল আছে কি না।

    Scanning-এর ধরনকী খোঁজে
    Network scanningজীবিত IP address
    Port scanningখোলা port ও সার্ভিস
    Vulnerability scanningপরিচিত দুর্বলতার উপস্থিতি

    Scanning-এর উদ্দেশ্য

    1. Live host ও তাদের IP খোঁজা।
    2. খোলা port খোঁজা — সিস্টেমে ঢোকার সেরা পথ।
    3. প্রতিটা port-এর সার্ভিস শনাক্ত।
    4. OS ও system architecture শনাক্ত — একে fingerprinting বলে; তারপর সেই OS-এর দুর্বলতা দিয়ে আক্রমণ।

    Network scanning

    • Non-targeted — ICMP scanning (ping): host-এ ICMP ECHO request পাঠাও; জীবিত হলে ECHO reply দেয়। Active device খোঁজা বা firewall ICMP যেতে দেয় কি না দেখতে কাজে লাগে।
    • Ping sweep: একটা IP range-এর কোনগুলো live host তা বের করা। সবচেয়ে জনপ্রিয় টুল nmap।
    • Targeted: পরিচিত সার্ভারের IP DNS দিয়ে বের করা — nslookup মনে আছে?

    Port scanning

    📖 উপমা

    Port হলো বাড়ির দরজা; port scanning মানে প্রতিটা দরজায় টোকা দিয়ে দেখা কোনটা খোলা। পরিচিত দরজা: web 80, FTP 21, SMTP 25 — আরও অনেক অ্যাপের জন্যও port খোলা থাকে। টুল: nmap।

    🧪 Ping sweep + port scan simulator (কাল্পনিক ল্যাব নেটওয়ার্ক 192.168.1.0/28)
    ⚖️ নৈতিকতা

    অনুমতি ছাড়া অন্যের নেটওয়ার্কে nmap চালানো বেআইনি হতে পারে। শুধু নিজের ল্যাবে বা লিখিত অনুমতি নিয়ে।

    ARP Spoofing

    ARP (IP → MAC ঠিকানা খোঁজার protocol) সরল ও কার্যকর, কিন্তু এর কোনো authentication নেই:

    • নেটওয়ার্কের যেকোনো কম্পিউটার দাবি করতে পারে “চাওয়া IP আমার”।
    • আরও খারাপ: কোনো মেশিন ARP reply পেলে — আগে request না পাঠালেও — নিজের ARP cache আপডেট করে ফেলে।

    ফলে LAN-এর ক্ষতিকর কেউ ARP spoofing করতে পারে।

    প্রতিকার

    • LAN access শুধু বিশ্বস্ত ব্যবহারকারীদের।
    • LAN-এ একই MAC address-এর একাধিক উপস্থিতি খোঁজা — সাধারণত এক MAC এক যন্ত্রের; একাধিক মানে সম্ভবত spoofed।
    • Admin-এর কনফিগার করা static ARP table — কিন্তু ঝামেলাপূর্ণ (প্রতিটা পরিবর্তনে হাতে আপডেট)।

    IP Spoofing

    Intruder এক IP থেকে packet পাঠায় যেন মনে হয় আরেক IP থেকে এসেছে (source address জাল)। Session authenticate করার পর server যদি ভাবে আসল উৎস থেকেই বার্তা আসছে, সে অজান্তে ক্ষতিকর আচরণ করতে পারে।

    Blind spoofingNon-blind spoofing
    কোথা থেকেযেকোনো উৎস থেকেএকই subnet থেকে
    Sequence/ACK numberদেখতে পায় না — অনুমান করতে হয়Sniffer দিয়ে packet দেখে pattern বের করে
    কঠিনতাকঠিনসহজ

    Blind: TCP/IP-তে session জুড়ে acknowledgement number পাঠাতে হয় (দুই পক্ষ নিশ্চিত হয় তারা একে অপরের packet পাচ্ছে)। IP পরিচয় spoof করতে ঠিক ACK sequence লাগে।

    Non-blind: একই subnet-এ sniffer দিয়ে packet decode করে ACK sequence pattern বের করে, তারপর আসল client-এর IP ও সঠিক sequence-এর ACK number দিয়ে সার্ভারে বার্তা পাঠায়।

    মোটিভেশন — উত্তর তো আসবে না, তাহলে কেন?

    Spoofed source দিলে উত্তর যায় সেই জাল ঠিকানায়, attacker-এর কাছে নয়। তাই IP spoofing ব্যবহার হয় এমন আক্রমণে যেখানে:

    • Attacker উত্তরের পরোয়া করে না — যেমন DoS: শুধু অন্য host-কে request দিয়ে ডুবিয়ে দিতে চায় (Smurf, SYN flood — Lecture 21)।
    • অথবা উত্তর পাওয়ার অন্য উপায় আছে — firewall policy ফাঁকি, TCP session hijacking।

    প্রতিকার

    ⚠️

    IP spoofing পুরোপুরি ঠেকানো যায় না, তবে সামলানো যায়।

    • Border router (দুই subnet-এর সংযোগে) এমনভাবে কনফিগার করা যে নিজের domain-এর বাইরের source address-ওয়ালা packet ভেতর থেকে বের হতে না পারে (ingress/egress filtering)।
    • IP traceback — packet-এর পথ ধরে আসল উৎস খোঁজা; তারপর পথের autonomous system-গুলোকে সেখান থেকে আসা packet block করতে বলা।
    • আসল উৎসের ISP-কে সন্দেহজনক মেশিন সম্পূর্ণ block রাখতে বলা, যতক্ষণ না malware-মুক্ত প্রমাণ হয়।
    একই subnet-এ বসে sniffer দিয়ে sequence number দেখে IP spoof করা — কোন ধরন?
    Subnet-এ বসে দেখতে পায় → non-blind।

    রিভিশন কুইজ

    ১) “Fabrication” কোন লক্ষ্যের বিরুদ্ধে?
    ভুয়া তথ্য তৈরি → integrity।
    ২) Sniffer ঠেকানোর সেরা উপায়?
    ধরলেও অর্থহীন garbage।
    ৩) OS ও system architecture শনাক্ত করাকে কী বলে?
    স্লাইড: এটাকে fingerprinting বলে।
    ৪) ARP spoofing কেন সম্ভব?
    Identity verification-এর অভাব।
    🎯 সম্ভাব্য পরীক্ষার প্রশ্ন
