    AES — Advanced Encryption Standard

    DES থেকে AES-এর গল্প, 4×4 state matrix, প্রতি round-এর ৪টা ধাপ (SubBytes, ShiftRows, MixColumns, AddRoundKey), key expansion (44 word, g() ফাংশন, Rcon), আর AES-এর একমাত্র বাস্তব আক্রমণ — timing side-channel। নিচে একটা আসল AES-128 আছে যেটা round-by-round দেখায়!

    📖 গল্প — AES প্রতিযোগিতা

    ১৯৯৭ সালে NIST বিশ্বব্যাপী ঘোষণা দিল: “DES-এর বদলি চাই!” পাঁচটা ফাইনালিস্ট: Rijndael (“Rhine doll”, বেলজিয়ামের Joan Daemen ও Vincent Rijmen), MARS (IBM), RC6 (RSA Security), Serpent (Anderson, Biham, Knudsen), Twofish (Bruce Schneier-এর দল)। পুরো প্রক্রিয়া ছিল উন্মুক্ত — Open design-এর চমৎকার উদাহরণ। জিতল Rijndael → নাম হলো AES।

    AES কাজ করে 128-bit block-এ; key 128, 192 বা 256 bit → AES-128, AES-192, AES-256।

    🎯 সূত্র

    Key schedule-এ word সংখ্যা = 4 × (rounds + 1) → 4×11 = 44, 4×13 = 52, 4×15 = 60। (+1 কারণ শুরুতে একটা অতিরিক্ত AddRoundKey।)

    State Array — 16 byte-এর 4×4 ম্যাট্রিক্স

    AES প্রতিটা 128-bit block-কে 16টা byte হিসেবে দেখে এবং column-major ক্রমে 4×4 ম্যাট্রিক্সে সাজায় — প্রথমে প্রথম কলাম উপর থেকে নিচে, তারপর দ্বিতীয় কলাম…

    in0 in4 in8 in12 s0,0 s0,1 s0,2 s0,3 in1 in5 in9 in13 → s1,0 s1,1 s1,2 s1,3 in2 in6 in10 in14 s2,0 s2,1 s2,2 s2,3 in3 in7 in11 in15 s3,0 s3,1 s3,2 s3,3

    ৪ byte = ১টা word (32 bit)। state-এর প্রতিটা কলাম একটা word। প্রতিটা round ইনপুট state নিয়ে আউটপুট state দেয়।

    🧪 16টা অক্ষর লিখে দেখো কীভাবে সাজায়

    প্রতি Round-এর ৪টা ধাপ

    AddRoundKey (w0–w3)→SubBytes→ShiftRows→MixColumns→AddRoundKey× 9, তারপর শেষ round-এ MixColumns বাদ

    S-box substitution: প্রতিটা byte-কে 16×16 lookup টেবিল থেকে বদলাও — byte-এর বাম nibble = সারি, ডান nibble = কলাম। (Lecture 6-এর S-box ধারণা!)

    0x53 → সারি 5, কলাম 3 → 0xED

    S-box গাণিতিকভাবে তৈরি: GF(2⁸)-এ multiplicative inverse, তারপর একটা affine transformation — এটাই AES-এর non-linear অংশ (confusion)।

    🧪 S-box lookup

    সরল permutation: প্রতিটা সারি বামে cyclically shift — সারি 0 → 0 ঘর, সারি 1 → 1 ঘর, সারি 2 → 2 ঘর, সারি 3 → 3 ঘর।

    Decryption-এ উল্টো: প্রথম সারি অপরিবর্তিত, বাকিগুলো ডানে 1, 2, 3 ঘর।

    🧪 ShiftRows অ্যানিমেশন

    প্রতিটা কলামের তথ্য মিশিয়ে দেয় — GF(2⁸)-এ Hill-cipher-এর মতো ম্যাট্রিক্স গুণ। প্রতিটা byte = নিজের 2 গুণ + পরের byte-এর 3 গুণ + তার পরেরটা + তার পরেরটা।

    [b0] [02 03 01 01] [s0] [b1] = [01 02 03 01] [s1] (+ মানে XOR, গুণ GF(2⁸)-এ) [b2] [01 01 02 03] [s2] [b3] [03 01 01 02] [s3] b0,j′ = (0x02·s0,j) ⊕ (0x03·s1,j) ⊕ s2,j ⊕ s3,j

    Decryption-এ inverse ম্যাট্রিক্স: [0E 0B 0D 09; 09 0E 0B 0D; 0D 09 0E 0B; 0B 0D 09 0E]

    🧪 একটা কলামে MixColumns

    পরিচিত টেস্ট: db 13 53 45 → 8e 4d a1 bc

    আগের ধাপের ফলাফলকে ঐ round-এর round key-এর সাথে XOR:

    b′i,j = bi,j ⊕ ki,j

    মূল চ্যালেঞ্জ: একটা 128-bit key K থেকে প্রতিটা round-এর ki,j ম্যাট্রিক্স কীভাবে আসে → Key Expansion। XOR নিজেই নিজের inverse, তাই decryption-এও একই ধাপ।

    📖 মনে রাখার গল্প — “চায়ের দোকানের তাস”

    ১৬টা তাস 4×4 সাজানো। SubBytes: প্রতিটা তাস একটা গোপন তালিকা দেখে অন্য তাসে বদলাও। ShiftRows: সারিগুলো বামে ঘোরাও (0,1,2,3)। MixColumns: প্রতিটা কলামের তাসগুলো ঘেঁটে মিশাও। AddRoundKey: গোপন চাবির নকশা উপরে চাপাও। ১০ বার করলে কেউ আর মূল সাজানো চিনতে পারবে না!

    Key Expansion — 4 word থেকে 44 word

    • 128-bit key-কে 4×4 byte array-তে সাজাও; প্রথম ৪ byte = w0, পরের ৪ = w1 … → [w0, w1, w2, w3]।
    • এগুলো বাড়িয়ে 44 word-এর schedule: w0 … w43।
    • [w0–w3] round শুরুর আগেই ইনপুটের সাথে XOR হয়; বাকি 40 word, প্রতি round-এ ৪টা করে, 10 round-এ।
    • w4–w7 = round 1-এর key, w8–w11 = round 2 …
    • লক্ষ্য: key-এর একটা bit বদলালে অনেকগুলো round key প্রভাবিত হবে।
    w[i+4] = w[i] ⊕ g(w[i+3]) (i যখন 4-এর গুণিতক — গ্রুপের প্রথম word) w[i+5] = w[i+4] ⊕ w[i+1] w[i+6] = w[i+5] ⊕ w[i+2] w[i+7] = w[i+6] ⊕ w[i+3]

    g() ফাংশন — তিন ধাপ

    ধাপ ১ — RotWord: 4-byte word-কে এক byte বামে cyclic rotate। [a0 a1 a2 a3] → [a1 a2 a3 a0]

    ধাপ ২ — SubWord: প্রতিটা byte-কে SubBytes-এর একই 16×16 S-box দিয়ে বদলাও।

    ধাপ ৩ — Rcon XOR: round constant-এর সাথে XOR: Rcon[i] = (RC[i], 0x00, 0x00, 0x00) — ডানের তিন byte শূন্য, তাই কার্যত শুধু বাম byte-এ XOR।

    RC-এর recursion: RC[1] = 0x01, RC[j] = 0x02 · RC[j−1] (GF(2⁸)-এ)

    RC: 01 02 04 08 10 20 40 80 1B 36

    উদ্দেশ্য: key expansion-এর অন্য ধাপগুলোতে যে symmetry তৈরি হতে পারে তা ভেঙে দেওয়া।

    192-bit key → 12 round, 52 word; 256-bit key → 14 round, 60 word। Block সবসময় 128 bit।

    AES-এর উপর আক্রমণ — Timing Side-Channel

    AES অত্যন্ত নিরাপদ; একমাত্র পরিচিত বাস্তব আক্রমণ হলো side-channel attack — অ্যালগরিদমের দুর্বলতা নয়, বরং implementation থেকে ফাঁস হওয়া তথ্য (সময়, বিদ্যুৎ, শব্দ…) ব্যবহার করে।

    ২০০৫ সালে আলাদাভাবে আবিষ্কার: Bernstein, এবং Osvik, Shamir ও Tromer।

    AES দ্রুত করতে lookup table ব্যবহার হয়। প্রসেসরের cache এই টেবিলের অংশ জমা রাখে।

    তাই অ্যালগরিদম চলতে কত সময় লাগে, তা থেকে বোঝা যায় টেবিলের কোন অংশ access হয়েছে (cache hit দ্রুত, miss ধীর)।

    একই key দিয়ে জানা plaintext/ciphertext-এ অনেকবার চালিয়ে সময় মাপলে attacker key শিখে ফেলে।

    • একই মেশিনে → এক সেকেন্ডেরও কম।
    • ভিন্ন মেশিনে → কয়েক ঘণ্টা।

    প্রতিরোধ: AES এমনভাবে implement করো যাতে cache architecture যা-ই হোক, execution time সবসময় সমান (constant-time) থাকে। আধুনিক CPU-তে AES-NI হার্ডওয়্যার instruction এই সমস্যা এড়ায়।

    📖 গল্প

    চোর তালার গোপন নম্বর জানে না, কিন্তু প্রতিটা ডায়াল ঘোরানোর সময় কান পেতে শোনে — সঠিক সংখ্যায় একটু অন্যরকম “ক্লিক” হয়। তালার নকশা নিখুঁত, কিন্তু শব্দ (side channel) সব ফাঁস করে দিল।
